# Salto KS: the system user activates IQs via the API only, never via the app

Remote open needs a self-computed OTP: the first 5 characters of `MD5(UTC "YYYYmmDDHHMMSS" + IQ secret + IQ PIN)`. The backend can only compute it while it holds the secret that the IQ currently trusts for the system user. The Connect API hands out that secret exactly once — `GET …/iqs/{iq}/secret` without an OTP returns the _first secret_, and only while the user has never been activated at that IQ. Activating the system user in the Salto mobile app performs its own handshake and **rotates the secret**; the app keeps the new one and no API endpoint ever returns it. A stored first secret then fails every locking call with `otp_invalid`, silently and permanently — this was the root cause of every failed door proof between 2026-08-19 and 2026-08-25.

We decided that the system user is activated **exclusively via the API**: fetch the first secret, trigger the initial PIN e-mail (`GET …/pin?send_email=true`), then activate with `PUT …/iqs/{iq}/pin {otp, delta: "0000"}` — `delta: "0000"` keeps the PIN equal to the mailed one (a real delta creates the PIN ambiguity that made `PATCH …/locking` reject OTPs which `PUT …/pin` had just accepted). The Salto app must never be used for the system user; there is no manual OTP entry anywhere in the platform, so an app-side activation has no upside and destroys the stored credentials. Proven at the door on the accept site on 2026-08-25 (`PATCH …/locking` → 200, remote opening confirmed in Salto's web app).

Consequences: the activation wizard and the stored `(secret, PIN)` per IQ on the tenant's Salto application (see `docs/specs/salto-ks-remote-open.md`) are the single source of OTPs; the client-supplied `otp` request parameter is removed. If the system user was ever activated through the app, the API cannot recover — the IQ (or the user's activation at it) must be reset on the Salto side, forcing all users of that IQ to re-activate. Tenant documentation must state plainly: do not log the system user into the Salto app.
